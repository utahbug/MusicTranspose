About MusicTranspose

About

MusicTranspose is a music workspace for viewing, transposing, organizing, and preparing music for rehearsal and performance. It is designed especially for musicians who want practical tools for working with music they are authorized to use, including music they add to the app themselves.

    About imported files

    Files that can be imported

    • PDF
    • MusicXML / MXL
    • Both, if available

    Either file type is fine. A PDF by itself works well for viewing and organizing music.

    Features of each file type

    PDF

    • Displays the original score
    • Allows annotation in the app
    • Allows Print / Save
    • Allows organization in Files, Lists, and Favorites

    Note: Transpose and Melody only are not available from a PDF alone.

    MusicXML / MXL

    • Allows score transposition
    • Provides Melody only when the score structure can be safely interpreted
    • Allows Print / Save as PDF
    • Allows MusicXML export for editing in music software

    Note: Annotation is not available in Transpose or Melody only.

    Playback and metronome

    • PDF only: standalone metronome with manual BPM; no score playback
    • MusicXML / MXL: score playback and score-synchronized metronome
