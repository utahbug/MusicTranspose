Library and icon polish

Implemented after the diagnostics-only release 9710055 was committed, deployed, and verified live. That investigation recorded 220 passing combined snapshots but did not reproduce the reported physical footer/navigation failures. Those symptoms still need a physical bad-state capture; this polish does not claim to fix them.

  1. Library Home: All Music; Children’s Songbook; Hymns for Home and Church; Hymns (1985); Lists; Files. Existing row dimensions, descriptions, subtle gradients and navigation retained.
  2. Detailed Library quick access: bottom-left Lists then Files, visible labels and 44px targets, restrained neutral surface. Lists uses outlined stacked collection cards; Files uses a folder with a small note. Both use the shared 24px/1.7px outline family.
  3. Lyrics: replaced unframed lines/note with a speech-bubble/text/note glyph after inspecting historical variants. Same 24px artwork, 1.7px stroke, 44px target, neutral surface, View Lyrics label/title and behavior.
  4. Clear all Favorites…: secondary More action, visible only when favorites exist. Native modal focuses Cancel and supports Escape/backdrop cancellation. Confirm clears only the favorites array, saves immediately, rerenders the filtered view, announces Favorites cleared., and restores focus to More. Lists, aliases, descriptions, source, sort and Search-in settings pass invariance assertions. Files model is untouched. Storage failure uses truthful session-only wording.
  5. Responsive: 390/430/820/1024/1440 passed. Phone full/reduced visual viewports, offsetTop 20 and simulated 34px safe clearance passed; controls remained hit-testable and no horizontal overflow occurred. Last Library row can scroll completely above the footer. The Library-only inset uses the actual fixed-footer anchor, removes its previous adjustment, and reserves content space. It does not modify Score/Lyrics inset or page-budget variables or emit score-layout events.
  6. Verification: node tests/library-polish.mjs; syntax checks for changed modules; git diff --check. Home order, both quick links, dialog Cancel/Escape/backdrop/Confirm, persisted state after reload, Lists isolation, icon bounds/stroke/labels, Lyrics return, and all five widths pass. Focused screenshots inspected at 390/820/1440. No broad score/harmony suites run.
